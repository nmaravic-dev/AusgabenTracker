# Ausgaben-Tracker (WPF / MVVM)

> 🚧 In Entwicklung

Desktop-Anwendung zur Erfassung persönlicher Ausgaben.
Entwickelt mit **C# / WPF** nach dem **MVVM-Muster**, mit **SQL-Server**-Anbindung (Dapper) und **Dependency Injection**.

## Technologien
- C# / .NET, WPF (XAML)
- MVVM (Model – View – ViewModel)
- Dapper + Microsoft SQL Server
- Dependency Injection (Microsoft.Extensions.DependencyInjection)
- Data Binding, INotifyPropertyChanged, ICommand
